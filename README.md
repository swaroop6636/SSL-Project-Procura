# Screenshots Directory

This directory stores visual screen captures of the Procura application in operation, as well as generated Matplotlib metric plots.

## Expected Files

1. **`process_monitor.png`**:
   - Screenshot of the primary **Process Monitor Panel**.
   - Displays the live process table with columns: PID, PPID, Name, State, %CPU, %Memory, and RSS.
   - Recommended size: 1280x720 or 1920x1080 PNG.

2. **`process_hierarchy.png`**:
   - Screenshot of the **Process Hierarchy Panel**.
   - Shows the interactive `JTree` illustrating parent-child process branches rooted at PID 1 (`systemd`/`init`).

3. **`scheduler_simulation.png`**:
   - Screenshot of the **Scheduler Simulation Panel**.
   - Shows the job configuration input table, algorithm selection controls, and simulation execution results.

4. **`gantt_chart.png`**:
   - Screenshot of the visual Gantt timeline rendered inside the GUI or exported as an artifact.

5. **`python_metrics_plot.png`**:
   - Matplotlib visualization generated by `python/plot_metrics.py`.
   - Displays comparative bar charts of Turnaround Time and Waiting Time across algorithms.

> **Note**: Both `docs/report/main.tex` and `docs/presentation/slides.tex` automatically detect if these images are present. If an image is missing, a boxed placeholder is displayed during LaTeX compilation.
